# Roblox MIDI Auto Piano

เล่นไฟล์ `.mid` / `.midi` ด้วยคีย์บอร์ดใน Roblox และดาวน์โหลด MIDI จาก MuseScore ในโปรแกรมเดียว

## ติดตั้งและเปิด

```sh
cd roblox-midi-player
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m playwright install chromium
python main.py
```

Windows ใช้ `.venv\Scripts\activate` แทน `source .venv/bin/activate`

## หน้าต่างแบบกะทัดรัด

หน้าหลักใช้โทนเข้มสไตล์มินิมอล พร้อมฟอนต์ Google Fonts (Kanit) ที่แนบมาในตัวโปรแกรม แสดงชื่อเพลง ปุ่มเล่น/พัก/หยุด ความคืบหน้า และสถานะ โดยอยู่เหนือหน้าต่างอื่น

- กด **MuseScore +** เพื่อเปิดส่วนดาวน์โหลด
- กด **ตั้งค่าการเล่น +** เพื่อสลับภาษา (ไทย / English) แก้พาธไฟล์ ผังคีย์ ความเร็ว นับถอยหลัง ทรานสโพส อ็อกเทฟ และการพับโน้ต
- เปิดได้ครั้งละหนึ่งส่วน กดปุ่มเดิมอีกครั้งเพื่อพับและย่อความสูงหน้าต่าง ค่าในช่องยังอยู่

ชื่อเพลงบนหน้าหลักจะเปลี่ยนตามไฟล์ที่เลือกหรือดาวน์โหลด หากเริ่มด้วย Python ที่ไม่มี `pynput` ให้เปิดจากโฟลเดอร์นี้ด้วย `.venv/bin/python main.py`

## โหลดจาก MuseScore

1. กด **MuseScore +** แล้ววาง URL หน้าเพลง เช่น `https://musescore.com/user/123/scores/456` หรือ score ID
2. กด **ดาวน์โหลด MIDI** โปรแกรมจะใช้ Chromium เบื้องหลังแบบ headless เพื่อโหลดหน้าและรับ token โดยไม่มีหน้าต่างเบราว์เซอร์เด้งขึ้นมา ไม่ต้องเปิด Google Chrome เอง
3. รอจนขึ้น **บันทึกแล้ว** ไฟล์ `.mid` จะอยู่ใน **current working directory ของโปรเซส** และถูกเลือกในช่องไฟล์ MIDI โดยอัตโนมัติ
4. กด **เริ่มเล่น (F8)** แล้วสลับไป Roblox ระหว่างนับถอยหลัง

ตัวอย่าง: รันจากโฟลเดอร์ `roblox-midi-player` ตามคำสั่งด้านบน ไฟล์จะเซฟในโฟลเดอร์นั้น หากรัน `python /path/to/roblox-midi-player/main.py` จากโฟลเดอร์อื่น ไฟล์จะเซฟในโฟลเดอร์ที่รันคำสั่ง

ชื่อไฟล์ใช้ชื่อเพลงจาก MuseScore ถ้ามีชื่อเดิมแล้วจะเพิ่ม ` (1)`, ` (2)` โดยไม่ทับไฟล์เก่า ตรวจว่า MIDI อ่านได้และมีโน้ตก่อนเซฟไฟล์สุดท้าย ไฟล์ชั่วคราวจะถูกลบเมื่อดาวน์โหลดหรือการตรวจสอบล้มเหลว

ปิด **ใช้ Chromium เบื้องหลัง** เพื่อทดลอง HTTP โดยตรงได้ แต่บางหน้าอาจยังต้องใช้ Chromium เบื้องหลังเพื่อจับ token ตามกลไกเดิมของไลบรารี ทุกเส้นทางใช้ headless และไม่เปลี่ยนไปเปิดหน้าต่างอัตโนมัติ หาก Cloudflare ต้องการการยืนยันหรือหน้าเพลงต้องล็อกอิน โปรแกรมอาจดาวน์โหลดไม่ได้และจะแสดงข้อผิดพลาด ยังต้องติดตั้ง Chromium ด้วย `python -m playwright install chromium` ตามขั้นตอนติดตั้ง

ระหว่างดาวน์โหลด UI ยังตอบสนอง แต่ปุ่มเล่นและ F8 จะรอจนดาวน์โหลดเสร็จ รอให้ดาวน์โหลดเสร็จก่อนปิดโปรแกรม โปรแกรมจะไม่เริ่มเล่นอัตโนมัติ

## เล่นไฟล์ที่มีอยู่

กด **เลือก...** แล้วเปิด `.mid` / `.midi` หรือรัน `python main.py song.mid`

- **F8** (หรือ **F9**): เริ่มเล่น / พักชั่วคราว / เล่นต่อจุดเดิมทันที (สลับวนได้ตลอดโดยไม่รีเซ็ตเพลง)
- **Esc**: หยุดและรีเซ็ตเพลงกลับจุดเริ่มต้น (Reset)
- **Shift+F9**: เร่งความเร็วขึ้นแบบเรียลไทม์ (+0.10x)
- **Shift+F8**: ลดความเร็วลงแบบเรียลไทม์ (-0.10x)

ปรับความเร็ว (Speed) ในช่องหรือใช้ปุ่มลัดได้ทันทีขณะกำลังเล่น เพลงจะเปลี่ยนความเร็วอย่างราบรื่นโดยไม่ต้องเริ่มใหม่

## ส่งออก Sheet Music

แปลงโน้ต MIDI เป็นตัวหนังสือตามฟอร์แมต Virtual Piano / Roblox (เช่น `[tpf] [yd] [uo]`):

- **ใน GUI**: กดปุ่ม **ส่งออก Sheet** (หรือ **Export Sheet**) ด้านข้างชื่อเพลง โปรแกรมจะแปลงโน้ต คัดลอกลงคลิปบอร์ดทันที และเปิดหน้าต่างพรีวิวพร้อมปุ่มคัดลอก/บันทึกลงไฟล์ `.txt`
- **ผ่าน CLI**:
  ```sh
  python main.py song.mid --sheet          # พิมพ์ Sheet Music ออกหน้าจอ terminal
  python main.py song.mid --sheet song.txt  # บันทึกลงไฟล์ song.txt
  ```

Roblox ต้องเป็นหน้าต่างที่ active ขณะเล่น บน macOS ให้สิทธิ์ Accessibility กับ Terminal/Python ใน System Settings
